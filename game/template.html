이 페이지는

Flash 게임 고군분투.swf(ActionScript 2)를 역컴파일한 로직 그대로 다시 만든 리메이크입니다. 물리, 충돌 박스, 레벨 맵, 코인 배치, 레벨업 규칙은 바이트코드에서 가져왔고 그림은 SWF 안의 도형, 비트맵, 타임라인을 그대로 그립니다.

조작 (HUMAN 모드)

  • 달리는 중에 화면 클릭(또는 터치, 스페이스바): 점프.
  • 공중에서 다시 클릭: 뚫어뻥 밧줄 발사. 탑 꼭대기에 닿으면 걸립니다.
  • 스윙 중에는 누르고 있으면 끌어올리고, 떼면 떨어집니다. 스윙이 끝나면 스핀 점프로 날아갑니다.

에이전트

입력 64개, 은닉층 2개(tanh), 출력 로짓 1개인 MLP가 매 프레임 마우스 버튼을 누를지 정합니다. PPO로 학습하며 보상은 생존 프레임당 +0.02, 클리어 +2, 사망은 0입니다. 시작 레벨, 진행도, 스크롤 위상을 무작위로 뽑고, 자주 죽는 레벨을 더 자주 뽑으며, 선택적으로 죽기 직전 상태를 다시 학습합니다.

입력은 캐릭터 상태, 밧줄 상태, 화면에 보이는 블록 6개, 남은 지면 시간, 그리고 게임 규칙으로 계산한 전방 예측 특징(지금 밧줄을 쏘면 탑에 걸리는가, 점프하거나 떨어지면 어디에 착지하는가)입니다. 화면에 없는 정보는 쓰지 않습니다. NETWORK 탭의 INPUTS에서 64개 입력을 모두 볼 수 있습니다.

브라우저에서 학습

TRAIN 탭에서 START FROM SCRATCH를 누르면 무작위 가중치에서 시작합니다. Web Worker마다 게임 복사본이 있어 PPO 기울기를 계산하고, 페이지가 평균해서 Adam으로 갱신합니다. 속도는 CPU 코어 수에 거의 비례하므로 WORKERS를 늘리세요. 단일 코어 실측으로 은닉 64, 약 175만 프레임(12분)에서 전체 게임의 77 %를 클리어했습니다. 사전학습 모델은 오프라인(C 시뮬레이터 + numpy)으로 약 9,830만 프레임을 학습했고 전체 게임의 약 99 %를 클리어합니다. CONTINUE PRETRAINED는 그 가중치에서 이어서 학습합니다.
